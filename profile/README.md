# Millennium Business Services, Inc. (MBSI)

Welcome to the MBSI GitHub organization.

This organization supports authorized company website development, internal projects, technical documentation, and source-code maintenance.

## About MBSI

Millennium Business Services, Inc. provides accounting, bookkeeping, payroll, financial reporting, tax compliance, and Xero-related support.

Visit the [MBSI website](https://mbsi.com.ph/) for company information, services, and contact details.

## Purpose of This Organization

- Maintain company website code and approved website assets.
- Organize development projects and technical documentation.
- Track improvements, fixes, and maintenance work.
- Support team collaboration and project handover.
- Maintain website releases and development backups.

## Website Development and Publishing

The original website uses WordPress and Elementor. Its static version
contains exported HTML, CSS, JavaScript, images, and other website assets.

Changes are developed and tested in WordPress before an approved static
export is published.

GitHub Pages does not run the WordPress dashboard, PHP application, or
database. Contact forms, applications, and other server-dependent features
require a separately configured submission service or backend.
